# Project images

These four files give a quick view of the main results:

- `model_comparison.png` — selected models and holdout metrics.
- `mortgage_backtest.png` — an example monthly holdout comparison.
- `m4_forecast.png` — the final M4 forecast and interval.
- `gbp_usd_forecast.png` — the final GBP/USD forecast and interval.

The notebook displays the full set of interactive charts when it runs. These PNGs are kept for the GitHub preview.
