# Generated outputs

Running the notebook updates these files:

- `econlens_model_leaderboard.csv` — every candidate model and its holdout metrics.
- `econlens_selected_models.csv` — the selected model for each series.
- `econlens_stationarity_report.csv` — ADF results and chosen differencing orders.
- `econlens_residual_diagnostics.csv` — Ljung-Box and Jarque-Bera checks.
- `econlens_backtest_predictions.csv` — actual and predicted holdout values.
- `econlens_final_forecasts.csv` — final forecasts and intervals.
- `econlens_model_card.csv` — a short summary of each selected model.
